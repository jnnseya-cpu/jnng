# Founder photography

Place the approved editorial portrait here as:

```
justin-nseya.jpg
```

The Founder page (`src/app/[locale]/founder/page.tsx`) detects this file at
build time and renders it automatically inside the gold-framed portrait with
the monochrome-to-colour hover treatment — no code change needed. Until the
file exists, a styled placeholder frame is shown instead.

Recommended: portrait orientation (3:4), at least 1200px wide, JPEG or WebP.

An optional second image (construction/project-site photograph) can be added
later as `justin-nseya-site.jpg` when the page is extended.
